# Правила разработки в репозитории `antigravity-model-router`

- **Рабочая копия и установленный плагин:** исходный код разрабатывается в текущем репозитории (`./`), а активный плагин Google Antigravity устанавливается в `~/.gemini/config/plugins/antigravity-model-router`.
- **Шаблон vs боевой конфиг (`router-state.json`):** файл `./router-state.json` в корне dev-репозитория — это чистый дефолтный шаблон для GitHub-релиза (`"subscriptionTier": "pro"`, отключённый GPU и т.п.). Реальные боевые настройки пользователя (подписка, RAM/GPU, пороги) лежат **только** в `~/.gemini/config/plugins/antigravity-model-router/router-state.json` — при проверке или диагностике конфига всегда читай установленный файл, а не шаблон в репо.
- **Обязательная установка после обновлений:** после завершения любых изменений кода, скиллов, правил, хуков или UI (`sidecars/panel/`) и прохождения проверок/тестов **всегда** запускай `node install.js`, чтобы синхронизировать обновлённые файлы в установленный плагин (с сохранением пользовательского `router-state.json`).
- **Локальные авто-коммиты (точки сохранения):** после завершения каждой задачи и успешного прохождения затронутых проверок/тестов автоматически делай локальный `git commit` **только по файлам, изменённым в текущей задаче** (`git add <file1> <file2> ...`, никогда не используй `git add -A` / `git add .`, чтобы не зацепить чужие незавершённые правки). Номер версии не меняй; при упавших тестах или незавершённой задаче коммит не делай.
- **Git-публикация:** не выполняй `git push` в удалённый репозиторий без явной просьбы пользователя.
- **Перезапуск:** при изменении только `sidecars/panel/ui.html` достаточно перезагрузить боковую панель; при правках `core/*.mjs`, `sidecars/panel/server.mjs`, `hooks.json` или `mcp_config.json` предупреждай пользователя, что для полного применения нужен перезапуск Google Antigravity.
